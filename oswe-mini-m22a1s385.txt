## ✨ The new feature
- **Overdue detection**:
  - Function: `isTaskOverdue(task: Task, now?: Date): boolean`  
  - Logic: a task is overdue when it has a `dueDate` strictly before today (day-precision) and its status is not `done`.
- **UI**:
  - In `FilterPanel`, a checkbox labeled **Show only overdue tasks** sets `filter.overdue` in the Task context. When checked only overdue tasks will be listed by the rest of the app’s filter logic.
- **Filtering**:
  - `filterTasks(tasks, filter)` now respects `filter.overdue`:
    - `true` → include only overdue tasks
    - `false` → exclude overdue tasks
    - `undefined | null` → ignore overdue status

## 🎓 How to Use

### Quick Start (3 Steps)

```typescript
// 1. Create a recurring task
const { addTask } = useTaskContext()
addTask({
  title: 'Weekly Standup',
  recurrence: {
    frequency: RecurrenceFrequency.Weekly,
    interval: 1,
    endDate: null,
    maxOccurrences: null,
    daysOfWeek: [1] // Monday
  }
  // ... other task properties
})

// 2. Generate instances
const { generateRecurringInstances } = useTaskContext()
generateRecurringInstances('task-id', 10)

// 3. Use the UI component
<RecurrencePanel 
  recurrence={recurrence}
  onRecurrenceChange={setRecurrence}
/>
```

### Available Methods

**Context Methods:**
- `generateRecurringInstances(taskId, count)` - Create instances
- `deleteTaskAndInstances(id)` - Delete parent + instances

**Utility Functions:**
- `getNextRecurrenceDate()` - Calculate next date
- `shouldCreateNextOccurrence()` - Validate constraints
- `createRecurrenceInstance()` - Create an instance
- `countRecurrenceInstances()` - Count instances
- `getRecurrenceInstancesForParent()` - Get all instances
- `deleteRecurrenceInstances()` - Remove instances
- `isTaskRecurring()` - Check if recurring
- `getRecurrenceDescription()` - Get description text
